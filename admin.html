Cara tambah akun

Satu akun Muse = satu API key. Kuota mengikuti subscription asli akun itu.

  1. Isi nama akun di form bawah, lalu klik Buat akun. Satu API key langsung dibuat untuk akun ini.
  2. Prompt reporter otomatis disalin ke clipboard — kirim ke Muse di mesin tempat akun itu login.
  3. Muse di mesin itu akan download reporter, test sekali (reported: 200), lalu pasang cron tiap 30 menit.
  4. Selesai — kuota real akun muncul di dashboard dan ikut mengendalikan limit.
